# Changelog

## [1.0.1] — 2026-09-30

Исправление белого окна при запуске / Fix for the white window on start.

- Пока интерфейс загружается, вместо пустого белого окна виден экран «Запуск Folio…»; если интерфейс не поднялся, Folio говорит, что случилось, и предлагает перезапуск в режиме совместимости, папку журнала или выход.
- Режим совместимости (без аппаратного ускорения графики): включается сам, если окно осталось пустым из‑за видеодрайвера или страницу интерфейса остановила проверка целостности кода (антивирус); вручную — `Folio.exe --compat` или *Настройки → Дополнительно*.
- В журнал пишутся версия WebView2, время загрузки страницы, сбои процессов WebView2 с кодом выхода и ошибки скрипта интерфейса.
- Самопроверка на GitHub Actions теперь запускает Folio и обычным образом (чистый профиль, первый запуск) и проверяет, что окно действительно показывает интерфейс и отвечает на мышь и клавиатуру.

## [1.0.0] — 2026-09-30

Первая версия / First release.

- Вкладки, сессия и «горячий выход», история версий файлов, слежение за изменениями файла другими программами.
- Распознавание и перекодирование ~30 кодировок, перевод в UTF-8 в один клик, предупреждение о символах, которых нет в выбранной кодировке, сохранение концов строк.
- Режимы «Обычный», «Кодер» (подсветка синтаксиса, номера строк, мини-карта) и «Корректор» (орфография словарями Windows, личный словарь, подсказки по пунктуации).
- Читалка для Markdown и выгрузок чатов с ИИ: книжная страница или лента, оглавление, выбор блоков для копирования.
- ИИ со своим ключом: исправление, сокращение, перевод, продолжение, объяснение кода; правки как рецензия. OpenAI, OpenRouter, DeepSeek, Groq, Mistral, Ollama, LM Studio и любой OpenAI-совместимый адрес.
- Трей, быстрые заметки по Ctrl+Alt+N, показ окна по Win+Alt+F, автозапуск с Windows.
- Темы «Бумага», «Графит», «Сепия», «Стекло», шрифты и масштаб интерфейса.
- Интерфейс на русском, английском и китайском, свои переводы по шаблону.
- Палитра команд, настраиваемые сочетания клавиш, журнал событий, обновления с GitHub с проверкой SHA-256.
