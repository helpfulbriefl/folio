# Changelog

## [1.1.0] — 2026-10-01

ИИ-профили, выбор модели, масштаб страницы, новая читалка / AI profiles, model picker, page zoom, a better reader.

- **ИИ:** исправлена ошибка «Index was out of range…» — её вызывали служебные фрагменты потока с пустым `choices: []` (у DeepSeek, OpenRouter и др.); ответы‑массивы, ответ SSE без потока и пустой ответ разбираются корректно. «A supported model is required» и похожие ответы сервера теперь показываются как понятная ошибка «Модель не поддерживается» с кнопкой выбора модели. / Fixed "Index was out of range" (stream chunks with empty `choices`), clear "model not supported" error.
- **Размышления модели** (`reasoning_content`, `<think>…</think>`) показываются отдельно, свёрнутым блоком «Думает…/Размышления», и не попадают в текст ответа и правки. Можно выключить в настройках.
- **Профили API:** несколько профилей (сервис, адрес, ключ, модель), видно, какой активен и у какого сохранён ключ; переключение из настроек и из панели ИИ. Ключи по‑прежнему хранятся зашифрованными (DPAPI), у каждого профиля свой. Старая настройка переносится автоматически. / Several API profiles, each with its own encrypted key.
- **Список моделей** загружается по ключу (`/models`) — выпадающий список с поиском и обновлением, предупреждение, если модели нет в списке.
- **Масштаб** (Ctrl+колесо, Ctrl+=/−) теперь увеличивает всю страницу — ширину листа, поля и отступы, а не только шрифт; в редакторе и в читалке.
- **Читалка:** Markdown делится по заголовкам (а не каждые ~3 предложения), короткие разделы объединяются, очень длинные делятся между абзацами; карточки шире (900 px по умолчанию), меньше служебных заголовков и пустых полей между страницами; длинная страница прокручивается внутри, колесо на краю листает дальше. Поддержаны `<kbd>`, `<sup>`, `<sub>`, `<br>` из README.
- **Вкладки:** настройка «Держать открытые вкладки / Всегда одна вкладка».
- **Типы файлов:** в *Настройках → Общие* можно связать с Folio .txt, .md, .json, .log, .csv, .xml, .yaml, .ini и др. (для текущего пользователя, без прав администратора) и открыть «Приложения по умолчанию» Windows.
- **Строка состояния** стала тонкой (24 px), в режиме фокуса — ещё тоньше.
- Значки файлов во вкладках по типу (developer-icons, MIT), мягкая «пружинная» анимация меню и панелей; можно выключить цветные значки.
- Новый раздел *Настройки → Поддержать*: GitHub проекта и «Buy me a coffee» (ETH).
- Самопроверка на GitHub Actions идёт на английском интерфейсе с английскими демо‑документами.

## [1.0.1] — 2026-09-30

Исправление белого окна при запуске / Fix for the white window on start.

- **Главное:** если одна из глобальных горячих клавиш Folio (<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> или <kbd>Win</kbd>+<kbd>Alt</kbd>+<kbd>F</kbd>) уже была занята другой программой, ответ оболочки на первый запрос интерфейса не отправлялся, и окно оставалось белым — не работал ни один пункт. Исправлено; кроме того, оболочка больше никогда не «теряет» ответ молча: если его не удаётся отправить, интерфейс получает ошибку, а в журнал пишется причина. / If a global hotkey was taken by another program, the reply to the interface's first request was silently dropped and the window stayed white. Fixed.
- Пока интерфейс загружается, вместо пустого белого окна виден экран «Запуск Folio…»; если интерфейс не поднялся, Folio говорит, что случилось, и предлагает перезапуск в режиме совместимости, папку журнала или выход.
- Режим совместимости (без аппаратного ускорения графики): включается сам, если окно осталось пустым из‑за видеодрайвера или страницу интерфейса остановила проверка целостности кода (антивирус); вручную — `Folio.exe --compat` или *Настройки → Дополнительно*.
- В журнал пишутся версия WebView2, время загрузки страницы, этапы запуска интерфейса, сбои процессов WebView2 с кодом выхода и ошибки скрипта интерфейса (в том числе до его старта).
- Самопроверка на GitHub Actions теперь запускает Folio и обычным образом (чистый профиль, первый запуск, трей и горячие клавиши) и проверяет, что окно действительно показывает интерфейс и отвечает на мышь и клавиатуру — именно этот запуск и нашёл ошибку.

## [1.0.0] — 2026-09-30

Первая версия / First release.

- Вкладки, сессия и «горячий выход», история версий файлов, слежение за изменениями файла другими программами.
- Распознавание и перекодирование ~30 кодировок, перевод в UTF-8 в один клик, предупреждение о символах, которых нет в выбранной кодировке, сохранение концов строк.
- Режимы «Обычный», «Кодер» (подсветка синтаксиса, номера строк, мини-карта) и «Корректор» (орфография словарями Windows, личный словарь, подсказки по пунктуации).
- Читалка для Markdown и выгрузок чатов с ИИ: книжная страница или лента, оглавление, выбор блоков для копирования.
- ИИ со своим ключом: исправление, сокращение, перевод, продолжение, объяснение кода; правки как рецензия. OpenAI, OpenRouter, DeepSeek, Groq, Mistral, Ollama, LM Studio и любой OpenAI-совместимый адрес.
- Трей, быстрые заметки по Ctrl+Alt+N, показ окна по Win+Alt+F, автозапуск с Windows.
- Темы «Бумага», «Графит», «Сепия», «Стекло», шрифты и масштаб интерфейса.
- Интерфейс на русском, английском и китайском, свои переводы по шаблону.
- Палитра команд, настраиваемые сочетания клавиш, журнал событий, обновления с GitHub с проверкой SHA-256.
